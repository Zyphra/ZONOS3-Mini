# Default voices

Each clip ships with its reference codes (`.codes.npy`, int32 `[frames, 10]`) and speaker embedding
(`.embedding.npy`, float32 `[192]`), so servers use them without the encoders. Pass this folder as
`--tts-default-voices-dir`; the ids below are those of `GET /v2/speakers`.
